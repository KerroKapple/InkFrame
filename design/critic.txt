## 二、矛盾（板名 + 改法）
1. **整组拖动的换道判据**。Selection 写「起拖 4px 内不判泳道」，但 fix/demo-lane-drag 已经实现了 `resolveCardDrop`：屏幕上拖动超过 18px、这一趟跨过带的边界、进新带至少 12px，三条都满足才换道，换了还弹撤销卡。
   - 改法：Selection 沿用 `resolveCardDrop` / `cardDropTargetLane`，整组时用抓住的那张卡来判（Q2 的 B）。4px 只用来区分「点」和「拖」。
2. **点卡的修饰键**。Selection 写「Shift 点卡加选、Ctrl 点卡反选（已实现）」，但 `canvas_view.dart:335-340` 里 Shift / Ctrl / ⌘ 都是切换。
   - 改法：照实写成「切换」；要改成加选，就列为改动项。macOS 上框选反选用 ⌘，因为 Ctrl+点在 mac 上是右键。
3. **临时不吸附用哪个键**。Selection 写按住 Ctrl(⌘)，ContextMenus 写按住 Alt。
   - 改法：统一成 Ctrl(⌘)。Alt 已经被切线和 Windows 菜单栏占了。
4. **拖卡时 Shift 有两个意思**。Selection 是锁轴，ContextMenus 是不插入叙事线。
   - 改法：Shift 只管锁轴；「不插入」并进 Ctrl，按住 Ctrl 就是原样放下、不吸附也不插入。
5. **批量生成什么时候确认，三种说法**。Selection Q4 是 ≥5 个或 ≥$5；ContextMenus 是多于 1 个就确认、单次最多 50；TakesCost 是「两个以上才弹」。
   - 改法：只留一条规则，归 TakesCost 的运行对话框，上限 50 也写在那里。
6. **批量顺序**。Selection 写按叙事序依次入队，TakesCost 写按 data 边依赖、下游等上游成功。
   - 改法：Selection 引用 TakesCost 的规则。
7. **价格未知的文案三种**：「另 1 个未知」「另有 N 个未知」「另 1 个价格未知」。
   - 改法：统一成「另 N 个价格未知」。
8. **导入 / 粘贴的媒体放哪**。UndoClipboard 写本画布 `images/`，ImportSearch 写本画布 `imports/`，ContextMenus 写「复制进项目目录」。
   - 改法：统一成 `canvases/<id>/imports/`，因为 `resolve` 不许越出画布根。
9. **剪贴板和拖放用哪个依赖**。UndoClipboard 写 super_clipboard，ImportSearch Q1 建议 desktop_drop + pasteboard。
   - 改法：UndoClipboard 和 ContextMenus 都改成引用 ImportSearch Q1。
10. **Ctrl D 的范围**。ImportSearch 写素材拖到空白处「同画布共用文件（同 Ctrl D）」，但代码里 `duplicateSources` 只复制配置节点。
    - 改法：改成「同画布粘贴」。
11. **F 键在有选中时**。RailScript 写「有选中时点泳道 = 包住选中（同 F）」，但代码里 F 是 `addLaneViaDialog`、不看选中，Selection 又把「包住」给了 Ctrl G。
    - 改法：RailScript 改成「有选中时 = Ctrl G」。
12. **重做的键位显示**。UndoClipboard 菜单写 Ctrl Y，ShellExport 编辑菜单写 Ctrl Shift Z。
    - 改法：动作表的主键 Windows 用 Ctrl Y、mac 用 ⇧⌘Z，两处显示同一个。
13. **迁移号撞车**。当前最新是 v8，而 RailScript 的 script_documents 和 ShellExport 的 export_records 都写了 v9。另外 canvas_templates、Selection Q6 选 C（style_lanes 加列）、ImportSearch Q5 选 B（便签做成新类型）也要迁移。
    - 改法：板上不写版本号，只写「新增一条前向迁移」，落地时按合入顺序编号。
14. **删除泳道的含义**。UndoClipboard 写「去掉确认，直接删 + 撤销卡」，没区分 ContextMenus 的「解散（节点留下）」和「删除泳道和内容（有生成中任务先确认）」。
    - 改法：两项分别进栈、分别命名。另外 ContextMenus 已经写死「新道插在最后一条目标道之后」，而这是 Selection Q5 还没定的事，改成引用 Q5。
15. **帮助有两套**。ShellExport 的帮助菜单（快捷键 / 检查更新 / 诊断包 / 日志 / 关于）和 RailScript 的帮助弹层（新手引导 / 示例 / 版本说明 / 反馈 / 手册 / 诊断包 / 日志 / 更新 / 关于）内容不同。
    - 改法：用同一组动作，菜单栏帮助 = 弹层的项 + 快捷键。
16. **新建节点的列表和叫法**。ShellExport「新建节点 ›」和 RailScript 节点库都没有便签 N；同一个类型，ShellExport 和工具条叫「分镜」，节点库和新建菜单叫「镜头」，属于 S5 那类问题。
    - 改法：统一一个叫法，并把便签加进两处。
17. **当前 take 和撤销栈**。
    - TakesCost Q1 选 A 时，系统会自动改写 data 边，这不进撤销栈；之后再撤一次「连线 / 改语义」就找不到原来那条边。
    - UndoClipboard 的进栈表里没有「设为当前 / 固定」，Q3 还用着旧名「转正」。
    - 改法：进栈表加「设为当前」（连同改写的边算一步）；反向操作按边两端的节点去找，不按边 id。
18. **重映射漏项**。ImportSearch 提示词里的 `@{角色 id}`、TakesCost `gen_inputs` 里的源节点 id，在项目包导入（`import_remapper`）、模板插入、跨项目粘贴时都要改写或剥掉。现在只点名了 `pinned_result_id`。
    - 改法：在 ImportSearch 和 TakesCost 的规则里各补一行。
19. **停用在批量对话框里没有状态**。TakesCost 的运行对话框没有「已停用」这一行状态，而 ContextMenus 说批量会跳过停用节点。
    - 改法：加一行「跳过 · 已停用」。
20. **耗时格式不一致**。ShellExport 系统通知写「1 分 12 秒」，同一张板的任务弹层规则是满 60 秒写 m:ss。
    - 改法：共用一个格式函数。
21. **Windows 按 Alt 聚焦菜单栏，和 Alt 组合键冲突**（ShellExport vs Selection 的 Alt A/D/W/S/H/V、Alt Shift H/V，以及 ContextMenus 的 Alt+拖）。
    - 改法：只有单独按下再松开 Alt、期间没有别的键或指针动作，才聚焦菜单栏；不做 Alt+字母的菜单助记键。
22. **币种**。B1 的 Main 稿写 ¥0.70，B2 全部用 $，代码是 `formatCostUsd`（USD）。
    - 改法：照 TakesCost Q6 选 A，改 B1 稿。
23. **RailScript 自相矛盾**。规则行写「`LeftRailPage` 加 nodeLibrary」，而它自己的 R7 建议选 B（并进模板页，不加键）。
    - 改法：规则行跟着 R7 走。
24. **Esc 归属太多**。菜单、@ 弹层、查找条、框选、工具锁、F6、清空选中都要用 Esc，没有一张板给出优先级。
    - 改法：定一个顺序，例如 菜单 > @ 弹层 > 查找 > 框选中 > 工具锁 > 清空选中。

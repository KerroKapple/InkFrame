关于 InkFrame
·菜单 / 右键菜单 / Ctrl K / 快捷键页共用一张动作表（id · 文案 · 键位 · 可用判据），改一处处处变
·不可用的灰着不藏，悬停说原因；「新」= 第二批的动作，接上之前一直灰着，不挂死交互
·点标签开，开着时划到相邻标签直接换开；←→ ↑↓ ↵ Esc。Esc 先关菜单——全局顺序：菜单 > @ 弹层 > 查找条 > 框选进行中 > 工具锁 > 清空选中
·Windows：只有单独按下再松开 Alt、期间没有别的键或指针动作，才聚焦菜单栏；不做 Alt+字母助记键——Alt A/D/W/S/H/V 对齐、Alt Shift H/V 分布、Alt+拖切线都归画布
·标签移出 DragToMoveArea：它的双击判定会让每次单击等 300ms（shell_chrome 头注）
·重做：动作表只有一个主键，Windows 显示 Ctrl Y，macOS 显示 ⇧⌘Z；菜单、快捷键页、撤销卡显示同一个
·新建节点 › 列全部可建类型，叫法与工具条 / 新建菜单 / 节点库同一份：图像配置 · 视频配置 · 文本 · 镜头 · 便签 · 泳道；工具条的 canvasToolShotNode「分镜节点」改叫「镜头节点」
·泳道… F 永远开新建泳道对话框，不看选中；把选中包成泳道走节点菜单「包成泳道」Ctrl G
·画布 / 节点两组只在画布标签可用；节点菜单的对象 = 当前选中集，与节点右键菜单同一判据；多选时「生成」= 批量生成，确认与上限只按 TakesCost 的规则
·帮助 = 左栏帮助弹层同一组动作 + 快捷键；有新版本时「检查更新…」换成「有新版本 x.y.z · 下载」，帮助键同时挂琥珀点
·macOS 用系统菜单栏 PlatformMenuBar（同一张表），chrome 不画这六个标签；关于 / 设置 / 退出进「InkFrame」应用菜单，键位显示 ⌘ ⌥ ⇧
需要你定
Q1 系统通知要不要出声？
A 系统通知静音，照常响 InkFrame 提示音 · B 只响系统的 · C 两个都响
建议 A：声音只听「提示音」设置，不会一次响两声
Q2 导出 / 交付进不进任务弹层？
A 进，作为另一类行，只在内存不落 jobs 表 · B 不进，只看进度卡
建议 A：长任务都在一处看、一处取消
Q3 导出历史留多久？
A 一直留，用户手动移除 · B 只留最近 50 条 · C 跟 jobs 一样按天数清
建议 A：一行很小，清掉就没法「重新导出」
Q4 分镜 PDF 的中文字体？
A 打包 Noto Sans SC（安装包 +10 MB 量级）· B 运行时嵌入系统字体（雅黑 / 苹方，授权要查）· C 首版只出图和英文字段
建议 A：两个平台排版一致，授权清楚

窗口不在前台时，跑了 10 秒以上的生成或导出做完，发一条系统通知。
·三个条件同时满足才发：卡片带 chime（后台事件）· 窗口不在前台 · 任务用时 ≥ 10 秒；失败也发
·前台判据复用 ToastCenter.setWindowActive
·点通知 = 窗口还原并聚焦 + 执行卡片主按钮（查看 → 定位节点，导出 → 打开文件夹）
·窗口里的卡照出、照进铃铛；2 秒内连着完成的合成一条
·「用时」与任务弹层同一个格式函数（见下）
·需新依赖 local_notifier（window_manager 同作者）；Windows 要开始菜单快捷方式带 AppUserModelID，macOS 首次开启时请求权限，被拒就在开关下写「系统里已关闭」

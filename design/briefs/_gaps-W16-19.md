# 第二批 W16–W19 设计缺口

写派工单时发现的画板缺口，供细化画板用。格式：画板 · 功能 · 缺什么（状态 / 步骤 / 边界）→ 派工单里暂定的做法。暂定做法都写进了对应派工单，画板补上后如果和暂定不一样，要回头改派工单。

## GapsCanvas
- **便签标题（note-heading-style）**
  - 选中和悬停时的样子没画 → 暂定：盒外画 1px accent 描边，悬停不画。
  - 标题为空时显示什么 → 暂定：最小宽 120，加占位字「空标题」。
  - 标题切回正文后，底色要不要恢复 → 暂定：底色值保留，不删。
  - 界面字号档位对画布里的标题生不生效 → 暂定：标题按 1.0 档测量和绘制。缩放低于 0.6 时，盒子按 0.6/缩放 反向放大，保证屏幕上不小于 12 号。
- **「更多」下拉（more-dropdown-panel）**
  - 菜单相对按钮怎么对齐、贴不下时往哪翻 → 暂定：右边对齐按钮、往下弹，贴边交给 CanvasMenuPopover。
  - 置灰原因的文案 → 暂定「还没有叙事链」。另外 CanvasMenuEntry 现在没有「置灰原因」字段。
  - 一次性切线模式开着时屏幕上有没有提示 → 暂定：轻提示胶囊「拖过要剪的线 · Esc 退出」。
  - 进入一次性模式后，点空白不拖算什么 → 暂定：按普通单击处理。模式是否保持没定。
  - 剪刀光标 → Flutter 没有系统剪刀光标，InkGlyph 也没有剪刀图标。暂定 `SystemMouseCursors.precise`。
- **新建菜单 · 角色组（create-menu-notes-characters）**
  - 打字时在哪个范围里搜 → 暂定：在全部角色里按名字匹配，最多 3 行。
  - 没有参考图的角色，缩略图位置画什么 → 暂定：characters 图标，加「0 张参考图」。
  - 新节点叫什么 → 暂定：用默认名。
  - 菜单开着时角色被删、再点它 → 暂定：不建节点，出错误卡「这个角色已被删除」。
  - 「建节点」组的顺序和别处不一致：样稿是「文本 · 便签 · 镜头」，节点库、工具锁和工具条是「文本 · 镜头 · 便签」。

## GapsPanels
- **通知位置（toast-corner）**
  - 上方两个角的卡片从哪进、往哪退 → 暂定：镜像处理，从上方进、往上退。
  - 画板写「40 标题栏、43 导航条」，和代码对不上（标题栏 31 + 标签栏 35，左栏宽 43）→ 暂定按代码常量取。
  - 在工作室、画廊等没有画布左栏的标签下，左角要不要让出 43 → 暂定：让出，换来所有标签下位置一致。
- **导入来源（assets-gallery-import-origin）**
  - 画廊里的「导入」筛选没画 → 暂定：放在「类型」组末尾，和图片 / 视频互斥。
  - 计数口径：画板上「全部 6 · 图片 3 · 视频 1 · 导入 2」加起来等于全部 → 按互斥划分做。副作用是选「图片」时看不到导入的参考图。
  - 导入还在复制中（uploading）时，素材格显不显示 → 暂定：按现状不显示。
- **一键导出（export-one-click）**
  - ▾ 的图（两项小菜单）和规则（「▾ = 现有对话框」）不一致 → 暂定按规则做；「上次：…」放进主体按钮的 tooltip。
  - 导出进行中按钮长什么样 → 暂定：整体置灰。

## ShellExport
- **分镜 PDF（storyboard-pdf-export）**
  - 没画的：导出对话框、PDF 页面版式（页眉 / 页脚 / 每格排法）、没有任何镜时的状态 → 派工单里按建议补了。
  - 字体：计划写 `NotoSansSC-Regular.otf`（CFF 轮廓），`package:pdf` 只认 TrueType → 派工单改成静态 `.ttf`。

## ImportSearch
- **小地图（canvas-minimap）**
  - 小地图和泳道工具栏（现在在 bottom 48）怎么叠 → 暂定：小地图放在泳道工具栏之上，bottom 84。
  - 宽度：样稿 160 超过令牌 `stageBottomLeftReserve = 176` 允许的上限 → 暂定宽 152。
  - 竖向泳道、折叠泳道、选中节点在小地图上的样子没画。
  - 查找条开着时小地图要不要让位，画板没说清 → 暂定：不让。
- **回到内容（back-to-content-chip）**
  - 样稿放在 top 10，会和浮动工具条重叠 → 暂定：挪到工具条下方 stageTopInset（64），和查找条互斥。
  - 连线模式下出不出现 → 暂定：不出现。节点全在折叠泳道里时也不出现。
  - 出现和消失的动效没画。
- **工具锁（tool-lock）**
  - 没锁时按 Q 锁哪个工具 → 暂定：锁工具条上最近点过的建节点工具，没点过就锁图像配置。
  - 锁定中按 I / G / T → 暂定：照常建一张，锁不变。
  - 占位框多大 → 暂定：真实卡片大小，以指针为中心。
  - 锁定中双击空白 → 暂定：不开新建菜单。
  - 锁定条在工具条下方、从 58 起，窄窗口下可能和查找条（64 起、居中）重叠，没画。

## ContextMenus
- **切线（cm-knife-cut）**
  - 红线的线宽和虚线节奏没写 → 暂定：线宽 1.5，虚线 4/3。
  - Alt + 单击（没拖）→ 暂定：按普通单击空白处理。
  - 一次性模式用什么光标 → 暂定 precise。
  - 快捷键页的「Alt 拖空白 = 切线」一行 → 由同波 shortcuts-page-v2 写进指针表。

## KeyMap
- **快捷键页（shortcuts-page-v2）**
  - 画板是两平台并排的总表，没画设置页里的段头、范围列和 Esc 阶梯的版式 → 暂定照 API 密钥页的表形。
  - 「单独 Alt」「文字让位」两块在设置页里怎么呈现 → 暂定：不单列。
  - 各个弹层内部的键表没有统一来源 → 暂定：在设置侧维护一张常量表 `overlay_key_catalog`。代价是弹层改键时测试不会变红。

## RailScript
- **重新导入（script-reimport-diff）**
  - 没画：入口、预览、确认按钮文案 → 暂定：剧本页头部放「重新导入…」，导入对话框加重导模式。
  - 只定义了同段 / 新段 / 删段，没有「改了几个字」的段 → 暂定加一类「改动 · 沿用原镜」，相似度 ≥ 0.6。
  - 没画：「原文已删」行长什么样、能不能手动清除 → 暂定只做标记。
  - 没画三种状态：比对期间剧本被别处改过（过期）、写库失败、原文没有变化。
  - 板上写「导入剧本」进撤销栈，重新导入进不进没写 → 暂定不进。
- **模板插入（template-core）**
  - 插进已有泳道的画布时，模板自己的泳道排在哪、横截方向怎么摆 → 暂定：追加在已有泳道之后，主轴居中，插完不在视口里就平移相机。
  - 横向画布存的模板插进竖向画布 → 暂定：坐标按主轴 / 横截轴存，自动转向。
  - 内置「短剧示例」画板写 4 镜，代码里的示例是 2 镜 → 以代码为准。
  - gen_inputs 怎么处理：RailScript 写「换新 id / 剥掉模板外的」，TakesCost 写「出现就剥掉」→ 按 TakesCost 一律剥掉，因为模板本来就不收产物。
- **模板页（rail-templates-page）**
  - 都没画：只有内置模板时要不要画「内置 | 我的」分段；卡片本体单击做什么；键盘怎么展开卡片；插入进行中卡片的样子；用模板新建画布后左栏停在哪页。
- **节点库（node-library-section / node-library-drag-recents）**
  - 都没画：节点库和模板卡之间怎么分隔；搜索框要不要也筛模板卡；全部筛空时显示什么；镜头没有单键。
  - 拖泳道「在落点开框」做不到：`createLane` 只能追加，落点决定不了位置 → 暂定等同按 F。
  - 预设行单击做什么 → 暂定：恰好选中一个图像 / 视频配置时套用，否则置灰并说明原因。
  - 「最近用过」条数：RailScript 写 5，GapsCanvas 写 3 → 照 `recentPresetsProvider` 返回的条数。时间行在 provider 不给时间时不画。
- **我的模板（my-templates-table）**
  - 存为模板对话框没画：要不要区分整张画布 / 选中的；空画布点了怎么办；允不允许重名；「我的」怎么排序。
  - 「我的」模板的右键菜单没有键盘入口；软删的行没有回收站，也没有清理。

## Selection
- **泳道折叠记忆（lane-collapse-persist）**
  - 写库失败时的状态没画 → 暂定：回滚，加 warn 日志，不出卡。

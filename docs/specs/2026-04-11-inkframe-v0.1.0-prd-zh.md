# InkFrame v0.1.0 — 产品需求文档

> 版本: 0.1.0
> 日期: 2026-04-11
> 状态: 草稿

---

## 1. 产品愿景

### InkFrame 是什么

开源、本地优先的 AI 影视创作工作站，面向短剧和影视制作。用户使用自己的 API Key（BYOK），完全在桌面端工作，数据完全归自己所有。

### 要解决的问题

- 现有 AI 视频创作工具全是 Web 端 SaaS 平台，API 调用赚大量差价
- Web 端渲染慢、卡顿，依赖服务器，数据不在用户手中
- 普通创作者用不起，专业人士觉得贵且受限
- AIGC 对普通人来说感觉高高在上、触不可及

### 核心主张

- **本地优先** — 数据存储在本地嵌入式 PostgreSQL，无需服务器，离线可用（AI 生成 API 调用除外）
- **BYOK（自带密钥）** — 用户填写官方或三方 API Key，零差价
- **开源免费** — MIT 协议，社区驱动
- **原生体验** — Flutter Desktop，macOS + Windows 原生渲染，不卡顿

### 目标用户

- 独立创作者（短剧、短视频、自媒体内容）
- 小团队工作室（2-5 人，无力承担 SaaS 费用）
- AIGC 爱好者（想尝试 AI 影视创作，但被现有工具门槛劝退）

### InkFrame 不是什么

- 不是在线协作平台（v0.1.0 纯本地单机）
- 不是视频剪辑软件（没有时间线/NLE）
- 不是模型训练工具

## 2. 核心用户场景

### 场景 1：从生图到生视频（P0 — 核心闭环）

```
创建画布 → 添加图片节点 → 写 prompt + 选模型 + 设参数
→ 生成 → 等待结果回填 → 拖出视频节点
→ 连线（图片 → 视频）→ 图片自动作为参考图
→ 配置视频参数（时长/运镜）→ 生成视频 → 预览/下载
```

用户有个画面想法，先生成一张图，迭代到满意，再基于这张图生成一段 5 秒视频。反复多组镜头素材。

### 场景 2：参考图驱动批量生产（P0）

```
拖入本地参考图到画布 → 从参考图拉连线到新图片节点
→ 连线类型选"参考" → 写 prompt 描述变化
→ 生成保持风格一致的新图 → 连到视频节点 → 生成视频
```

用户已有角色设定图，想基于同一角色生成不同场景/动作的图片，保持风格一致性。

### 场景 3：剧本驱动分镜生产（P1）

```
导入/粘贴剧本文本 → AI 解析剧本 → 自动拆分为 场景(Scene) + 镜头(Shot) 结构
→ 每个 Shot 获得：叙事描述 + 镜头语言 + 六维分析
→ 系统为每个 Shot 生成多宫格 prompt
→ 生成九宫格/四宫格图（一张图内多个关键帧，天然保持一致性）
→ 自动裁切为独立关键帧图片
→ 用户在画布上审查：满意的保留，不满意的编辑/重新生成
→ 把通过的关键帧拖入分镜 Shot 节点
→ Shot 节点：关键帧横向排列 + 叙事 prompt
→ 点击"生成视频" → 多参考图生视频（Kling/Seedance）
→ 视频结果显示在 Shot 节点内 → 画布上可预览
```

#### 分镜 Shot 节点设计

```
+----------------------------------------------------------------------+
| Shot #1  "主角推门进入"  中景·推镜头                                   |
| 叙事: 主角缓步推开沉重的木门，室内昏暗，逆光剪影                        |
|                                                                      |
|  关键帧（横向排列，可增减）：                            +--------+   |
|  +------+ +------+ +------+ +------+                   | 🎬生成 |   |
|  | 帧1  | | 帧2  | | 帧3  | | 帧4  |  ...              |  视频  |   |
|  |      | |      | |      | |      |                   |        |   |
|  +--+---+ +--+---+ +--+---+ +--+---+                   +--------+   |
|     |✕       |✕       |✕       |✕                                    |
|                                                                      |
|  提示词: A man pushes open a heavy wooden door, dim interior...      |
|  模型: Kling 3.0 多图参考 | 时长: 5s | 运镜: 推                      |
|                                                                      |
|  +--------------------+                                              |
|  | ▶ 生成的视频预览    |                                              |
|  +--------------------+                                              |
+----------------------------------------------------------------------+
```

**画布与分镜的关系：**
- 画布 = 创作空间（自由生图、九宫格、编辑、迭代）
- 分镜 = 生产线（把画布里 OK 的素材组织起来生成视频）
- 画布上的图片节点可以被多个 Shot 节点引用
- Shot 里的关键帧是画布图片的 **引用**，不是复制
- Shot 之间通过叙事顺序连线连接，在画布上可见
- 生成的视频直接显示在画布上的 Shot 节点内

#### 多宫格生图（一致性保障机制）

每个 Shot 的内容生成一张多宫格图（四宫格或九宫格），因为在同一张图中生成，天然保证所有关键帧的风格/角色/光照一致。

```
九宫格生成 → 自动裁切 → 9 张独立关键帧图片
→ 用户保留有用的，删掉/编辑不好的
→ 通过的关键帧添加到 Shot 节点作为视频参考图
```

宫格数量随模型能力提升而增加：4 → 9 → 16+

### 场景 4：资产复用与管理（P2）

```
生成满意的角色图 → 右键"保存为资产"
→ 标注：名称、类型、触发词
→ 后续：新节点 → @提及该角色资产 → 自动注入参考图 + 触发词
→ 保持整部作品角色一致性
```

## 3. 风格分区系统

### 问题

没有风格管理，连续镜头可能在真人和动漫风格之间跳变，破坏视觉连贯性。不同场景（餐厅白天、街道雨夜、便利店荧光灯）需要各自独立的氛围定调。

### 方案：风格泳道

画布被划分为 **风格泳道** — 横向或纵向的色带，每个泳道有独立的背景色调，泳道之间是渐变分界线。

```
+----------------------------------------------------------------------+
| 🎨 项目基底风格: 真人电影，4K，电影质感                       [编辑]  |
+----------------------------------------------------------------------+
|                                                                      |
|  🎨 室内餐厅 · 暖光 · 黄昏                                          |
|  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 暖橙色底 ░░░░░░░░░░░░░░░░░|
|                                                                      |
|    [图片] [图片] [Shot#1] ──→ [Shot#2]                               |
|                                                                      |
|══════════════════ 渐变分界线（暖橙渐变到冷蓝）══════════════════════ |
|                                                                      |
|  🎨 街道 · 雨夜 · 霓虹                                              |
|  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 冷蓝色底 ░░░░░░░░░░░░░░░░░|
|                                                                      |
|    [图片] [Shot#3] ──→ [Shot#4] ──→ [Shot#5]                        |
|                                                                      |
|══════════════════ 渐变分界线 ════════════════════════════════════════ |
|                                                                      |
|  🎨 便利店 · 荧光灯 · 深夜                                          |
|  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 青白色底 ░░░░░░░░░░░░░░░░░|
|                                                                      |
|    [Shot#6] ──→ [Shot#7]                                             |
|                                                                      |
+----------------------------------------------------------------------+
```

### 风格区域可描述的内容

| 类型 | 示例 |
|------|------|
| 场所 | 餐厅、办公室、街道、天台 |
| 时间 | 清晨、黄昏、深夜 |
| 天气 | 雨、雪、雾、晴 |
| 光线 | 逆光、侧光、霓虹、烛光 |
| 氛围 | 紧张、温馨、诡异、浪漫 |
| 画风 | 写实、国漫、水墨、赛博朋克 |

### 风格注入逻辑

生成任何图片/视频时，prompt 自动拼接：

```
最终 prompt = 项目基底前缀
            + 最外层泳道风格
            + ...（嵌套泳道）
            + 最内层泳道风格
            + 节点自身 prompt
            + 项目基底后缀
```

### 操作方式

| 操作 | 方式 |
|------|------|
| 新增分区 | 分界线上点 "+" 按钮，或工具栏按钮 |
| 删除分区 | 右键分区标题 → 删除（节点归入相邻分区） |
| 调整大小 | 拖拽分界线 |
| 移动节点 | 节点拖过分界线 → 自动继承新分区风格 |
| 排序分区 | 拖拽分区标题调整顺序 |
| 横竖切换 | 工具栏按钮切换横向/竖向布局 |
| 编辑风格 | 双击分区标题栏 |
| 自动配色 | 根据风格关键词自动匹配背景色；可手动覆盖 |
| 跳过风格 | 单个节点可勾选"忽略区域风格"（用于实验/对比） |

## 4. 连线类型

| 连线类型 | 含义 | 视觉样式 |
|---------|------|---------|
| **参考引用** | 图片节点 → Shot 关键帧或图片节点（风格/内容参考） | 虚线，蓝色 |
| **叙事顺序** | Shot#1 → Shot#2 → Shot#3（故事顺序） | 实线，白色/金色 |
| **风格参考** | 图片 → 图片（风格迁移） | 虚线，紫色 |
| **生成来源** | 九宫格 → 裁切出的子图 | 细线，灰色 |

## 5. AI 交互模型

### 方案：内联面板 + 命令栏（混合模式）

**单节点操作** → 点击节点 → 内联面板（快速高效）：
- Prompt 输入框
- 模型选择器（按能力过滤：图片/视频）
- 比例、时长、运镜
- 参考图拖入区域
- 高级参数：负面提示词、种子
- [生成] 按钮

**批量/智能操作** → ⌘K 命令栏：
- v0.1.0：仅斜杠命令（`/生成`、`/批量生成`）
- P1+：AI 对话能力（自然语言 → 批量操作选中节点）

## 6. 功能模块与 MVP 边界

### P0 — v0.1.0（画布核心 + 生图生视频闭环）

| 模块 | 功能 |
|------|------|
| **画布引擎** | 节点拖拽、缩放、平移、连线；Flutter 自绘画布 |
| **图片节点** | prompt 输入、模型选择、参数配置、生成、预览 |
| **视频节点** | 单图生视频、文生视频、预览播放 |
| **多宫格生图** | 九宫格/四宫格生图、自动裁切为独立图片节点 |
| **连线系统** | 参考引用、风格参考、生成来源；不同类型不同视觉样式 |
| **风格分区（泳道）** | 画布分区、色调背景、渐变分界线、风格 prompt 自动注入 |
| **项目/画布管理** | 创建/打开/保存/删除画布，项目基底风格 |
| **Provider 接入：生图** | Gemini、即梦 4.5、Kling 图片 |
| **Provider 接入：生视频** | Kling 3.0（单图生视频）、海螺 |
| **API Key 管理** | 设置页面填写各 Provider Key；macOS Keychain / Windows 凭据管理器 |
| **国际化** | 100% 英文 + 中文覆盖 |

### P1 — 分镜生产线 + 剧本解析

| 模块 | 功能 |
|------|------|
| **Shot 节点（分镜）** | 横向关键帧槽位、叙事 prompt、生成视频按钮、视频预览；画布上可见，叙事连线 |
| **关键帧管理** | 从画布图片拖入 Shot、排序、删除、替换；引用关系，不是复制 |
| **多参考图生视频** | Kling 多图参考、Seedance；关键帧 + 叙事 prompt → 视频 |
| **剧本导入与解析** | 粘贴/导入文本 → AI 拆分为 Scene + Shot；提取叙事、镜头语言、角色 |
| **命令栏** | ⌘K 唤起，斜杠命令：`/生成`、`/批量生成` |
| **导出：分镜** | 选中 Shot → 按叙事顺序自动排列 → 导出（见导出章节） |
| **导出：画布** | 选中/全选视频节点 → 按空间位置自动排列 → 导出 |

### P2 — 资产管理 + 智能化

| 模块 | 功能 |
|------|------|
| **资产库** | 角色/场景/道具资产；保存、标注触发词、@提及注入；跨画布复用 |
| **AI 对话** | 命令栏升级为多轮对话；批量智能操作 |
| **批量生成** | 分镜表一键批量提交，队列管理，并发控制 |
| **更多 Provider** | Sora、Veo 3.1、Wanx 等 |

### 明确排除

| 排除项 | 原因 |
|--------|------|
| 时间线 / NLE 剪辑 | 不做剪辑软件，专注素材生产 |
| 在线协作 | v0.1.0 纯本地单机 |
| 模型训练 / LoRA | 超出范围 |
| 音频生成 | 后续版本考虑 |
| 移动端 | 桌面优先 |
| Linux | v0.1.0 不在范围内 |

## 7. 导出系统

### 两个导出入口

| 入口 | 选择范围 | 排序逻辑 |
|------|---------|---------|
| **画布导出** | 选中/全选画布上的视频节点 | 按空间位置（左→右、上→下） |
| **分镜导出** | 选中/全选 Shot 节点 | 按叙事连线顺序 |

两个入口支持相同的输出格式。

### 输出格式

| 格式 | 目标软件 | 优先级 |
|------|---------|--------|
| **序号命名文件 + ZIP** | 通用 | P1 |
| **EDL** (.edl) | 所有 NLE 软件 | P1 |
| **剪映草稿** (.json) | 剪映专业版 | P1.5 |
| **FCPXML** (.fcpxml) | Final Cut Pro | P2 |
| **AAF** (.aaf) | Premiere Pro、After Effects、DaVinci Resolve | P2 |
| **DaVinci Resolve XML** (.xml) | DaVinci Resolve | P2 |

### 输出目录结构

```
InkFrame_Export_20260411/
├── 001_Shot1_主角推门.mp4
├── 002_Shot2_对话.mp4
├── 003_Shot3_反派转身.mp4
├── project.edl                    ← 时间线工程文件
├── metadata.json                  ← 序号 + 时长 + prompt
└── storyboard.txt                 ← 分镜脚本文本
```

### 导入剪辑软件后的效果

- 视频片段自动排列在 V1 轨道上，按序号顺序
- 带音频的视频（如 Veo 3.1 生成的）音轨自动分离到 A1 轨道
- 片段名称保留 Shot 标题，方便识别
- 首尾相接，无间隙
- 用户只需在剪辑软件里：加转场、调色、加音乐、精修

### 音频处理

- 模型返回的视频自带音轨（如 Veo 3.1）：音频原样保留
- 导出时视频（V1）和音频（A1）分离到不同轨道
- 不带音频的模型：仅 V1 有内容，A1 为空

### 单节点下载

右键任意图片/视频节点 → 下载 → 原始文件保存到本地。

## 8. 非功能需求

### 性能

| 指标 | 要求 |
|------|------|
| 画布节点数 | 200+ 节点，流畅 60fps 交互 |
| 画布缩放/平移 | 无卡顿，GPU 加速渲染 |
| 图片加载 | 缩略图懒加载，大图按需加载 |
| 视频预览 | 节点内直接播放，不弹新窗口 |
| 冷启动时间 | < 3 秒 |
| 内存占用 | 100 节点画布 < 1GB 内存 |

### 存储

| 项目 | 方案 |
|------|------|
| 项目/画布/节点数据 | 本地嵌入式 PostgreSQL |
| 生成的图片/视频文件 | 本地文件系统，按项目/画布目录组织 |
| API Key | macOS Keychain / Windows 凭据管理器 |
| 用户设置 | 本地 JSON 配置文件 |
| 云端依赖 | 无，除 AI 生成 API 调用外 |

### 平台

| 平台 | 优先级 | 最低系统版本 |
|------|--------|------------|
| macOS | P0 | macOS 12+（Monterey） |
| Windows | P0 | Windows 10 21H2+ |
| Linux | 不计划 | — |

### 网络

| 场景 | 处理方式 |
|------|---------|
| 离线状态 | 画布编辑、节点管理、项目管理全部可用 |
| 生成请求 | 需联网，调用 Provider API |
| 断网重连 | 生成任务自动重试（指数退避，最多 3 次） |
| 代理支持 | 系统代理 + 手动设置代理地址 |

### 安全

| 项目 | 要求 |
|------|------|
| API Key | 仅存平台安全存储，不写入数据库/日志/配置文件 |
| 数据隐私 | 所有数据本地存储，不上传任何遥测数据 |
| 开源审计 | MIT 协议，代码完全公开 |

### 国际化

| 语言 | 覆盖率 |
|------|--------|
| English | 100%（开发语言，source of truth） |
| 中文 | 100%（每次提交同步） |

> 日期: 2026-04-11
> 状态: 草稿

## 1. 产品愿景

### InkFrame 是什么

开源、本地优先的 AI 影视创作工作站，面向短剧和影视制作。用户使用自己的 API Key（BYOK），完全在桌面端工作，数据完全归自己所有。

### 要解决的问题

- 现有 AI 视频创作工具全是 Web 端 SaaS 平台，API 调用赚大量差价
- Web 端渲染慢、卡顿，依赖服务器，数据不在用户手中
- 普通创作者用不起，专业人士觉得贵且受限
- AIGC 对普通人来说感觉高高在上、触不可及

### 核心主张

- **本地优先** — 数据存储在本地嵌入式 PostgreSQL，无需服务器，离线可用（AI 生成 API 调用除外）
- **BYOK（自带密钥）** — 用户填写官方或三方 API Key，零差价
- **开源免费** — MIT 协议，社区驱动
- **原生体验** — Flutter Desktop，macOS + Windows 原生渲染，不卡顿

### 目标用户

- 独立创作者（短剧、短视频、自媒体内容）
- 小团队工作室（2-5 人，无力承担 SaaS 费用）
- AIGC 爱好者（想尝试 AI 影视创作，但被现有工具门槛劝退）

### InkFrame 不是什么

- 不是在线协作平台（v0.1.0 纯本地单机）
- 不是视频剪辑软件（没有时间线/NLE）
- 不是模型训练工具

## 2. 核心用户场景

### 场景 1：从生图到生视频（P0 — 核心闭环）

```
创建画布 → 添加图片节点 → 写 prompt + 选模型 + 设参数
→ 生成 → 结果输出到新节点 → 满意则从结果节点拖出连线到视频节点
→ 连线自动传递参考图 → 配置视频参数（时长/运镜）
→ 生成视频（结果输出到新视频节点）→ 预览/下载
```

用户有个画面想法，先生成一张图，迭代到满意，再基于这张图生成一段 5 秒视频。反复多组镜头素材。

### 场景 2：参考图驱动批量生产（P0）

```
拖入本地参考图到画布 → 从参考图拉 data 连线到新图片节点
→ 写 prompt 描述变化 → 生成保持风格一致的新图（输出到新节点）
→ 连到视频节点 → 生成视频
```

用户已有角色设定图，想基于同一角色生成不同场景/动作的图片，保持风格一致性。

### 场景 3：剧本驱动分镜生产（P1）

```
导入/粘贴剧本文本 → AI 解析剧本 → 自动拆分为 场景(Scene) + 镜头(Shot) 结构
→ 每个 Shot 获得：叙事描述 + 镜头语言 + 六维分析
→ 系统为每个 Shot 生成多宫格 prompt
→ 生成九宫格/四宫格图（一张图内多个关键帧，天然保持一致性）
→ 自动裁切为独立关键帧图片
→ 用户在画布上审查：满意的保留，不满意的编辑/重新生成
→ 把通过的关键帧拖入分镜 Shot 节点
→ Shot 节点：关键帧横向排列 + 叙事 prompt
→ 点击"生成视频" → 多参考图生视频（Kling/Seedance）
→ 视频结果显示在 Shot 节点内 → 画布上可预览
```

#### 分镜 Shot 节点设计

```
+----------------------------------------------------------------------+
| Shot #1  "主角推门进入"  中景·推镜头                                   |
| 叙事: 主角缓步推开沉重的木门，室内昏暗，逆光剪影                        |
|                                                                      |
|  关键帧（横向排列，可增减）：                            +--------+   |
|  +------+ +------+ +------+ +------+                   | 生成   |   |
|  | 帧1  | | 帧2  | | 帧3  | | 帧4  |  ...              | 视频   |   |
|  |      | |      | |      | |      |                   |        |   |
|  +--+---+ +--+---+ +--+---+ +--+---+                   +--------+   |
|     |x       |x       |x       |x                                   |
|                                                                      |
|  提示词: A man pushes open a heavy wooden door, dim interior...      |
|  模型: Kling 3.0 多图参考 | 时长: 5s | 运镜: 推                      |
|                                                                      |
|  +--------------------+                                              |
|  | > 生成的视频预览    |                                              |
|  +--------------------+                                              |
+----------------------------------------------------------------------+
```

**画布与分镜的关系：**
- 画布 = 创作空间（自由生图、九宫格、编辑、迭代）
- 分镜 = 生产线（把画布里 OK 的素材组织起来生成视频）
- 画布上的图片节点可以被多个 Shot 节点引用
- Shot 里的关键帧是画布图片的引用，不是复制
- Shot 之间通过叙事顺序连线连接，在画布上可见
- 生成的视频直接显示在画布上的 Shot 节点内

#### 多宫格生图（一致性保障机制）

每个 Shot 的内容生成一张多宫格图（四宫格或九宫格），因为在同一张图中生成，天然保证所有关键帧的风格/角色/光照一致。

```
九宫格生成 → 自动裁切 → 9 张独立关键帧图片
→ 用户保留有用的，删掉/编辑不好的
→ 通过的关键帧添加到 Shot 节点作为视频参考图
```

宫格数量随模型能力提升而增加：4 → 9 → 16+

### 场景 4：资产复用与管理（P2）

```
生成满意的角色图 → 右键"保存为资产"
→ 标注：名称、类型、触发词
→ 后续：新节点 → @提及该角色资产 → 自动注入参考图 + 触发词
→ 保持整部作品角色一致性
```

## 3. 画布引擎交互规格

### 3.1 视口操作

| 操作 | 触发方式 | 行为 |
|------|---------|------|
| 平移 | 鼠标中键拖拽 / 空格+左键拖拽 / 触控板双指滑动 | 视口平移，节点不动 |
| 缩放 | Mod+滚轮 / 触控板捏合 / 工具栏 +/- 按钮 | 以鼠标位置为中心缩放 |
| 缩放范围 | — | 最小 10%，最大 400%，默认 100% |
| 适应全部 | 可配置快捷键 | 视口缩放到刚好包含所有节点，留 10% 边距 |
| 缩放到选中 | 可配置快捷键 | 视口缩放到刚好包含选中节点 |
| 重置视口 | 可配置快捷键 | 回到 100% 缩放，原点居中 |

### 3.2 选择操作

| 操作 | 触发方式 | 行为 |
|------|---------|------|
| 单选节点 | 左键点击节点 | 选中该节点，取消其他选中，弹出内联面板 |
| 追加选中 | Mod+左键点击 | 切换该节点的选中状态，不影响其他 |
| 框选 | 左键在空白区域拖拽 | 绘制选框，松开时选中框内所有节点 |
| 追加框选 | Mod+左键在空白区域拖拽 | 框内节点追加到已选中集合 |
| 全选 | 可配置快捷键 | 选中画布上所有节点 |
| 取消全选 | Escape / 点击空白区域 | 清空选中状态 |
| 选中连线 | 左键点击连线 | 选中该连线，高亮显示 |

### 3.3 节点操作

| 操作 | 触发方式 | 行为 |
|------|---------|------|
| 移动节点 | 选中后左键拖拽 | 节点跟随鼠标移动；多选时所有选中节点同步移动 |
| 删除节点 | 可配置快捷键 | 移入回收站 + 级联断开所有连线 |
| 复制 | 可配置快捷键 | 复制选中节点到剪贴板（含参数，不含生成结果） |
| 粘贴 | 可配置快捷键 | 在鼠标位置粘贴，偏移 (20, 20) 防重叠 |
| 复制粘贴 | 可配置快捷键 | 原地复制 + 偏移 (40, 40) |
| 撤销 | 可配置快捷键 | 撤销上一步操作 |
| 重做 | 可配置快捷键 | 重做上一步撤销 |
| 右键菜单 | 右键点击节点 | 弹出上下文菜单 |

### 3.4 连线操作

| 操作 | 触发方式 | 行为 |
|------|---------|------|
| 创建连线 | 从节点连接点拖出 | 显示拖拽线条，靠近目标节点时吸附高亮 |
| 删除连线 | 选中连线后按删除键 | 删除连线 |
| 连线验证 | — | 不允许自连接；不允许重复连线（同源同目标同类型） |

### 3.8 快捷键系统

**所有快捷键均可在设置中自定义。**

快捷键配置数据结构：
```
{
  "action_id": "canvas.select_all",
  "label": "全选",
  "category": "canvas",
  "default_binding": "Cmd+A / Ctrl+A",
  "user_binding": null,
  "context": "canvas_focused"
}
```

上下文隔离：不同上下文（canvas_focused / node_selected / global）的键位可以相同不算冲突。

冲突检测：录入新键位时如果冲突，提示用户选择覆盖或取消。

平台感知：macOS 显示 Cmd，Windows 显示 Ctrl，存储用通用标识符（mod）。

持久化：`~/.inkframe/config/keybindings.json`

设置页面支持搜索、按分类浏览、录入新键位、恢复默认。

### 3.9 性能档位与用户偏好系统

四个预设 + 自定义模式：

| 预设 | 定位 |
|------|------|
| 省电 | 老设备，最大限度降低资源占用 |
| 均衡（默认） | 主流配置，平衡画质和性能 |
| 性能 | 高配电脑，更好的视觉效果 |
| 极致 | 最佳画质，不限制资源 |

可自定义的参数维度：

**节点渲染：** 缩略图质量（128/256/512/原图）、视频预览（首帧/悬停播放/自动播放）、离屏节点渲染（不渲染/简化/完整）、节点阴影（关/简单/柔和/多层）、节点动画（关/状态切换/全部/粒子）

**画布：** 背景网格（关/点阵/点阵+线）、风格泳道背景（纯色/渐变/渐变+模糊）、抗锯齿（关/基础/2x/4x）

**连线：** 渲染（直线/贝塞尔/流动/粒子）

**交互：** 拖拽反馈（无/影子/高亮/吸附动画）、缩放动画时长（0-350ms）

**系统：** 最大可见节点数（50-无限）、缩略图缓存大小（100MB-1GB）、渲染帧率上限（30/60/不限）、GPU 加速（关/基础/完整）、撤销历史步数（20-200）

**首次启动自动检测：** 检测内存、GPU、CPU 核心数，推荐合适档位。

**运行时动态降级：** 内存 > 80% 自动释放缓存，帧率 < 30fps 自动关闭动画，恢复后静默恢复设置。

持久化：`~/.inkframe/config/performance.json`

### 3.10 节点标签位置自定义

所有标签元素（名称、模型、比例、状态等）的位置和显示条件可自定义。

**可放置位置：** 内侧 9 个锚点 + 外侧 8 个锚点 + 隐藏。

**显示条件：** 始终显示 / 悬停显示 / 选中显示 / 隐藏。

**编辑方式：** 设置 → 节点标签布局 → 拖拽编辑界面。左侧可用元素列表，右侧实时预览节点。拖拽元素到预览节点的锚点上，自动吸附。预览区可切换模拟状态（默认/悬停/选中）。

**内置预设：** 极简（默认）、信息丰富、制片模式。用户可保存自定义预设。

持久化：`~/.inkframe/config/node_layout.json`

## 4. 图片节点

### 4.1 节点视觉规则

**核心原则：图片永远是视觉主体，文字信息不遮挡媒体内容。**

**默认状态：** 纯净图片，无任何文字覆盖。节点名称在右下角外侧，纯文字无背景无边框（默认预设，可自定义位置）。

**悬停状态：** 连接点出现（横向泳道：左入右出；竖向泳道：上入下出）。右上角浮出操作图标（菜单 + 查看原图），小尺寸不遮挡。

**选中状态：** 高亮边框 + 连接点。弹出内联面板。

**生成中状态：** 半透明蒙层 + 居中小型圆形进度指示器（百分比）。

**错误状态：** 红色边框 + 居中错误图标 + 可点击重试。

**空状态：** 虚线边框 + 居中"点击编辑"文字。

### 4.2 查看原图

| 触发方式 | 行为 |
|---------|------|
| 悬停时点击放大镜图标 | 全屏灯箱查看原图 |
| 右键 → 查看原图 | 同上 |
| 可配置快捷键（节点选中时） | 同上 |

灯箱功能：暗色半透明背景、原始分辨率显示、滚轮缩放、拖拽平移、九宫格子图可左右切换同组图片、下载按钮、Escape 关闭。

### 4.3 节点状态机

```
创建 → idle → (用户点击生成) → generating → success / error / cancelled
                                                ↓
                                          error → (重试) → generating
```

生成结果永远输出到新节点，原节点保持不变。

### 4.4 节点数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 唯一标识 |
| type | "image" | 节点类型 |
| label | String | 用户可编辑的标题 |
| status | Enum | idle / uploading / generating / success / error / cancelled |
| prompt | String | 提示词 |
| negativePrompt | String? | 反向提示词 |
| model | String | 模型 ID |
| aspectRatio | String | "1:1" / "16:9" / "9:16" / "4:3" / "3:4" / "21:9" |
| resolution | String | "720p" / "1080p" / "2K" / "4K" |
| seed | int? | 随机种子 |
| imageUrl | String? | 生成结果本地文件路径 |
| thumbnailUrl | String? | 缩略图路径 |
| sourceNodeId | String? | 由哪个节点生成而来 |
| isGridGeneration | bool | 是否为九宫格/四宫格生成 |
| gridType | String? | "2x2" / "3x3" / null |
| gridChildren | List\<String\>? | 裁切后子图片节点 ID 列表 |
| parentGridId | String? | 从九宫格裁切出来的父节点 ID |
| batchResults | List\<BatchResult\>? | 批量生成结果 |
| error | String? | 错误信息 |
| progress | double | 生成进度 0.0-1.0 |
| taskId | String? | Provider 异步任务 ID |
| text | String? | 仅文本节点使用 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |
| deletedAt | DateTime? | 软删除时间戳，null 表示未删除 |
| position | Offset | 画布坐标 (x, y) |
| size | Size | 节点尺寸，固定宽度，高度按图片比例自适应 |
| zIndex | int | 层级，最近操作的自动置顶 |

### 4.5 生成行为规则

**核心原则：生成结果永远输出到新节点，原节点不被覆盖。**

```
[节点A] ──generation_source──→ [节点B]（新建，承载结果）
 (保持原样)                     (继承 A 的 prompt/模型/参数快照)
```

每次生成都创建新节点。用户可以从任何有 prompt 的节点发起生成。结果节点也可以修改 prompt 再次生成。

**自动布局：** 新节点自动放置在源节点右侧 60px，多个结果节点竖向排列。

### 4.6 九宫格/四宫格生成

```
用户选择"九宫格 3×3"模式 → 生成一张完整九宫格大图（输出到新节点）
→ 新节点显示完整九宫格 → 点击[自动裁切为 9 张]
→ 创建 9 个子图片节点，自动排列在父节点下方
→ 父 → 子之间自动创建 generation_source 连线
→ 用户挑选满意的子图做后续使用
```

裁切规则：等分图片，子节点继承父节点 prompt + 位置标注，命名 `{父标题}_1` ~ `{父标题}_9`。删除父节点时提示是否同时删除子节点。

### 4.7 拖入本地文件

| 拖入内容 | 行为 |
|---------|------|
| 本地图片文件（png/jpg/webp） | 创建图片节点，存入项目目录，status: success |
| 多个图片文件 | 每个创建一个节点，自动排列 |
| 从浏览器拖入图片 | 下载到本地，创建节点 |
| 不支持的文件类型 | Toast 提示 |

## 5. 视频节点

### 5.1 视觉规则

与图片节点一致。默认显示首帧画面，名字 + 时长在右下角外侧。悬停时出现播放按钮（居中半透明圆形）和连接点。

### 5.2 视频节点数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 唯一标识 |
| type | "video" | 节点类型 |
| label | String | 标题 |
| status | Enum | idle / uploading / generating / success / error / cancelled |
| prompt | String | 提示词 |
| negativePrompt | String? | 反向提示词 |
| model | String | 模型 ID |
| mode | Enum | text_to_video / image_to_video |
| aspectRatio | String | 比例 |
| resolution | String | 分辨率档位 |
| duration | int | 时长（秒） |
| cameraMovement | String? | 运镜预设 ID |
| seed | int? | 随机种子 |
| videoUrl | String? | 生成结果本地路径 |
| thumbnailUrl | String? | 首帧缩略图路径 |
| hasAudio | bool | 是否包含音轨 |
| sourceNodeId | String? | 由哪个节点生成 |
| error | String? | 错误信息 |
| progress | double | 0.0-1.0 |
| taskId | String? | Provider 异步任务 ID |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |
| deletedAt | DateTime? | 软删除时间戳 |
| position | Offset | 画布坐标 |
| size | Size | 节点尺寸 |
| zIndex | int | 层级 |

### 5.3 两种生成模式（P0）

**文生视频：** 纯文字 prompt，无参考图。

**图生视频：** data 连线连入图片 → 自动切换为图生视频模式，参考图自动填入。断开连线后自动切回文生视频。

P1 新增：多参考图生视频（Kling 多图参考、Seedance）。

### 5.4 播放行为

| 触发 | 行为 |
|------|------|
| 悬停 + 点击播放按钮 | 节点内播放，默认静音 |
| 查看原视频 | 灯箱全屏播放，带控制条 |
| 灯箱控制条 | 播放/暂停、进度拖拽、音量（有音轨时）、倍速、循环、下载 |
| 节点内播放结束 | 显示最后一帧静止 |

| 菜单项 | 行为 |
|--------|------|
| 提取首帧为图片 | 创建新图片节点 |
| 提取末帧为图片 | 创建新图片节点 |
| 提取帧... | 进度条选帧 → 创建图片节点 |

## 6. 文本节点

### 6.1 用途

存放文本内容（剧本片段、描述、备注），通过 data 连线传递给图片/视频节点作为关联 prompt。

### 6.2 外观

默认状态直接显示文本内容，无边框装饰。节点名称在右下角外侧。双击进入编辑模式，直接在节点内编辑文本。

### 6.3 数据模型

复用 nodes 表，type = "text"，text 字段存储文本内容，prompt/imageUrl/videoUrl 为 null。

### 6.4 连线行为

文本节点通过 data 连线连到图片/视频节点后：
- 目标节点内联面板顶部显示关联文本标签
- 生成时文本拼接到 prompt 中（风格注入之后、用户 prompt 之前）

```
最终 prompt = 项目基底前缀 + 泳道风格 + 关联文本 + 用户 prompt + 项目基底后缀
```

## 7. 风格泳道系统

### 7.1 核心概念

画布划分为风格泳道——横向或纵向的色带，每个泳道有独立背景色调和风格描述，泳道之间是渐变分界线。

### 7.2 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 唯一标识 |
| label | String | 泳道名称 |
| stylePrompt | String | 风格描述文本 |
| order | int | 排列顺序 |
| tintColor | Color? | 背景色调，null 时自动推断 |
| size | double | 泳道宽度（竖向）或高度（横向） |

### 7.3 泳道视觉

**背景色自动推断：**

| 关键词 | 色调 |
|--------|------|
| 暖/黄昏/餐厅/烛光 | 暖橙 |
| 雨/夜/冷/霓虹 | 冷蓝 |
| 荧光/白/医院/办公 | 青白 |
| 森林/自然/草地 | 深绿 |
| 恐怖/暗/废墟 | 深紫 |

用户可手动覆盖选色。

**分界线：** 两个泳道之间 40px 渐变过渡带 + 1px 细线。悬停分界线时显示 "+" 按钮。性能省电模式降级为纯实线。

**泳道标题栏：** 泳道顶部（横向）或左侧（竖向），半透明背景条。悬停显示编辑和菜单按钮。

### 7.4 风格注入逻辑

```
最终 prompt = 项目 baseStylePrefix + 泳道 stylePrompt + 节点自身 prompt + 项目 baseStyleSuffix
```

内联面板底部实时显示拼接预览。

### 7.5 泳道操作

| 操作 | 方式 |
|------|------|
| 创建 | 分界线 "+" / Dockbar 按钮 / 空画布首次创建 |
| 编辑 | 双击标题栏弹出编辑浮窗（名称、风格描述、背景色） |
| 调整大小 | 拖拽分界线 |
| 排序 | 拖拽标题栏 |
| 横竖切换 | 工具栏按钮 |
| 折叠 | 双击分界线折叠为标题条 |
| 删除 | 标题栏菜单，弹出确认 |

### 7.6 节点与泳道

- 节点中心点所在泳道 = 归属泳道
- 拖拽跨越分界线 → 目标泳道高亮 → 松手后归属切换
- 已生成结果不受影响，仅下次生成使用新风格
- 泳道外的节点只继承项目基底风格
- 单个节点可勾选"忽略区域风格"

### 7.7 项目基底风格

顶部导航栏显示当前基底风格，点击编辑弹窗：
- 前缀输入框（插入到所有 prompt 最前面）
- 后缀输入框（插入到所有 prompt 最后面）
- 快速预设：真人电影 / 国漫 / 吉卜力 / 赛博朋克 / 水墨 / 写实摄影 / 3D动画

### 7.8 风格区域可描述的内容

场所、时间、天气、光线、氛围、画风——完全自由，用户可写一个词也可写一长段。

## 8. 连线系统

### 8.1 三种连线类型

| 类型 | 用途 | 视觉 | 创建方式 |
|------|------|------|---------|
| **data** | 节点间传递数据 | 实线，蓝色 | 用户手动拖拽 |
| **narrative** | Shot 间叙事顺序（P1） | 实线，金色 | 用户手动 |
| **generation_source** | 配置→结果、九宫格→子图 | 细线，灰色 | 系统自动 |

### 8.2 data 连线的动态适应

连线只管传数据，模型能力决定怎么用。

多张图连入同一视频节点时，内联面板根据模型能力动态展示：
- 模型支持多图参考 → 全部作为参考图，可排序
- 模型只支持单图 → 用户选择其中一张
- 模型支持首尾帧 → 用户可切换为首尾帧模式，从连入图中选
- 模型不支持图片输入 → 参考图区域隐藏，连线不影响生成

### 8.3 连线创建流程

从连接点拖出 → 靠近目标吸附 → 松手 → 直接创建 data 连线。

特殊情况：目标是 Shot 节点（P1）时弹出选择 data 或 narrative。只有一种可能时不弹选择。generation_source 由系统自动创建，用户不可手动创建。

### 8.4 连线副作用

| 事件 | 自动行为 |
|------|---------|
| data 连入视频节点 | 自动切换为图生视频模式 |
| 所有 data 断开 | 自动切回文生视频模式 |
| 删除节点 | 级联断开所有连线 |

### 8.5 连线验证

不允许自连接。不允许重复（同源同目标同类型）。narrative 不允许成环（必须是 DAG）。

### 8.6 连线视觉

默认低透明度（30%），悬停 80%，选中 100%。关联节点选中时 60%。拖拽连线中其他连线降到 10%。

具体渲染效果（直线/贝塞尔/流动/粒子）跟随性能档位。

## 9. 内联面板（统一规格）

### 9.1 定位与外观

- 宽 740px，高度自适应（280px 起）
- 位于节点正下方 16px，水平居中
- 顶部小三角指向节点
- 入场动画 0.15s 缩放+淡入
- 单击任何节点弹出，不受缩放比例影响
- 面板固定尺寸渲染，不跟随画布缩放
- 多选时隐藏面板，显示批量操作栏

### 9.2 面板布局

```
参考图区域（仅模型支持且有内容时显示）
  或 首尾帧区域（互斥，根据模型能力和内容切换）
关联文本标签（从文本节点连入时显示）
提示词输入框（支持 / 斜杠命令和 @ 资产引用）+ 优化按钮
底部工具栏
```

### 9.3 底部工具栏

横向排列，自动换行：

1. **模型选择器** — 只显示当前节点类型匹配的模型，未配 Key 的标"未配置"
2. **画质/比例** — 弹窗：比例按钮组 + 分辨率 [720p] [1080p] [2K] [4K]，模型不支持的不显示
3. **批次** — 模型支持时显示 [1x] [2x] [4x]
4. **时长** — 仅视频 + 模型支持时，只显示支持的选项
5. **运镜** — 仅视频 + 模型支持时，弹窗网格图标选择
6. **高级设置** — 模型声明了任意高级参数时显示（种子/反向提示词/Steps/CFG/音频开关）
7. **生成按钮** — 白底右对齐，显示预估 Token 消耗，无 prompt 时灰掉

**核心原则：模型不支持的能力完全隐藏，不灰掉，不占空间。切换模型时面板平滑重排。**

### 9.4 斜杠命令

输入 `/` 或 `、` 触发命令菜单，内联定位在输入框上方。方向键导航，回车选择，输入过滤。

预置命令：/grid-9 九宫格、/grid-4 四宫格、/lighting 补光、/3view 三视图。

### 9.5 @ 资产引用（P2，面板预留）

输入 `@` 触发资产面板。三个一级 Tab：人物 / 资产（含环境/道具二级分类）/ 画布（当前画布图片节点）。选中后参考图自动加入 + 触发词拼入 prompt。

### 9.6 键盘操作

Enter（无 Shift）提交生成，Shift+Enter 换行，Escape 关闭面板。所有键盘事件 stopPropagation 防触发画布快捷键。

### 10.3 统一生成流程

| 内容审核拒绝 | 提示修改 prompt |
| 网络超时 | 提示检查网络 |
| Provider 服务异常 | 提示稍后重试 |
| 轮询超时 | 提示服务繁忙 |

### 10.5 代理配置

设置 → 网络：使用系统代理 / 手动配置 / 不使用。支持 Provider 级别覆盖（不同 Provider 用不同代理）。

## 14. 删除与回收站

### 14.1 删除行为

所有删除操作（节点、连线、泳道、画布、项目）先进回收站，不立即删除文件。数据库标记 `deleted_at` 时间戳。

节点删除无需确认（支持撤销），画布删除需确认弹窗，项目删除需输入名称确认。

### 14.2 回收站

每个项目独立回收站。入口：设置 → 存储 → 打开回收站。

按时间分组显示已删除项目，支持单项恢复/永久删除、清空回收站。显示占用空间。

恢复逻辑：恢复到原位；如果依赖的上级对象已删除则提示先恢复上级。

### 14.3 自动清理

回收站默认保留 30 天（可配置），超期自动永久删除。永久删除时真正删除数据库行和文件系统文件。

## 15. 缓存系统

### 15.1 缩略图系统

**生成时机：** 图片生成成功、视频生成成功（提取首帧）、拖入本地文件、九宫格裁切。

**四个档位：** micro (64px)、small (128px)、medium (256px)、large (512px)，JPEG 格式。

**按性能档位选择：** 省电→small，均衡→medium，性能→large，极致→原图。

### 15.2 内存缓存（LRU）

| 参数 | 省电 | 均衡 | 性能 | 极致 |
|------|------|------|------|------|
| 最大缓存数 | 30 | 80 | 150 | 300 |
| 预估内存 | ~50MB | ~150MB | ~300MB | ~600MB |

LRU 淘汰，优先淘汰离屏节点。加载优先级：视口内 > 1屏外 > 2屏外。

### 15.3 离屏节点渲染

视口内正常渲染，视口外按距离和性能档位逐级降级为缩略图 → 占位框（颜色块+标题）→ 不渲染。

缩放 < 30% 时所有节点降级为占位框。

### 15.4 缓存清理

源文件永久删除时清理对应缩略图。磁盘超限时淘汰最旧的。启动时扫描孤立缩略图。

设置 → 存储可查看和清理缓存，配置缩略图缓存上限。

## 16. 撤销/重做机制

### 16.1 操作栈

双栈（undo + redo），每画布独立，栈深跟随性能档位（20-200），不持久化。

### 16.2 可撤销操作

创建/删除/移动节点、编辑 prompt/参数、创建/删除连线、创建/编辑/删除泳道、编辑文本节点、九宫格裁切。

### 16.3 不可撤销操作

发起生成（消耗 API 额度）、永久删除（清空回收站）。

### 16.4 redo 清空

撤销后执行任何新操作 → redo 栈清空。

## 17. 通知/Toast 系统

### 17.1 位置

画布右下角，堆叠显示。

### 17.2 类型

| 类型 | 图标 | 自动消失 | 场景 |
|------|------|---------|------|
| 成功 | ✅ | 5 秒 | 生成完成、导出完成 |
| 错误 | ⚠ | 不消失 | 生成失败、Key 无效 |
| 信息 | ℹ | 3 秒 | 自动保存、性能降级 |
| 进行中 | ⟳ | 完成后消失 | 导出中 |

### 17.3 生成完成跳转

Toast 内"点击跳转到节点" → 画布自动平移缩放到结果节点位置。

用户滚到远处时，长任务 Toast 显示进度百分比。

## 20. 非功能需求

### 性能

| 指标 | 要求 |
|------|------|
| 画布节点 | 200+ 节点 60fps |
| 冷启动 | < 3 秒 |
| 内存 | 100 节点 < 1GB |

### 平台

| 平台 | 最低版本 |
|------|---------|
| macOS | 12+ (Monterey) |
| Windows | 10 21H2+ |

### 网络

离线可用（除生成 API），生成任务自动重试（指数退避，最多 3 次），支持代理。

### 安全

API Key 仅平台安全存储，无遥测，MIT 开源。

### 国际化

English 100% + 中文 100%，每次提交同步。

**Tech Stack:** Riverpod、既有 AlertDialog/TextButton 对话框惯例、ARB。

/// 回收站行（项目/画布共用形状）。
class TrashedItem {
  const TrashedItem({required this.id, required this.name, required this.deletedAt});
  final String id; final String name; final DateTime deletedAt;
}

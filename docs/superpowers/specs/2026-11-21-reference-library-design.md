# 参考库：素材页第三段（设计）

- 日期：2026-11-21
- 状态：已确认（方案 A；换一张 = 替换）
- 概念图：方案 A（<https://claude.ai/artifact/98QoNpJXhfUR7qmUCt6spz> 的「A · 素材页第三段」）

## 为什么做

Kerro 想把本机下载的 ai-pose-gallery-zh 图库（姿势白模、人像、服装）当参考图用在画布上，两种用途：

1. **定姿势**：挂在某一镜上，当这一镜的姿势 / 构图参考，每一镜都可以换。这是主用途。
2. **定长相**：存成角色，所有镜头共用。图库里的脸不是用户自己的角色，所以这是次要用途。

## 目标 / 不做 / 失败标准

- 目标：在左栏素材页里浏览、搜索、筛选图库，点一张就能当成当前镜头的参考图，或者存成角色。
- 不做：
  - 图片不进仓库，不进安装包（许可：图片版权归原作者，不许商用）。
  - 动漫服装、CharaDB 两个子库只有指向原站的链接，没有本地图，不接。
  - 深度图不接。
  - 不把姿势名、服装关键词写进提示词（发给模型的只用英文；服装虽然有英文关键词，也留到以后）。
  - 不加新的左栏页，不做拖拽，不做面板拉宽。
- 失败标准：点了「当姿势参考」，生成时却没用上这张图（又一个 TOPO-2）；或者没设文件夹 / 文件夹不对时界面崩溃、白屏。

## 选了哪种做法

三种做法，Kerro 选了 A：

- **A · 素材页加第三段「参考库」**（选定）：改动最小，左栏还是三页，组件全部复用。缺点是 241 宽只放得下两列。
- B · 素材页分两层，面板可拉宽，以拖拽为主：浏览最舒服，但要做拉宽和拖放，工作量大。
- C · 检查器里弹大窗：精确挑图顺手，但必须先选中一镜才能打开。

## 设计

### 界面（照概念图 A）

- 素材页的分段从「本画布 / 项目全部」变成「本画布 / 项目全部 / 参考库」。
- 切到「参考库」时：
  - 搜索框（按条目自带的「检索」字段做子串匹配）。
  - 类别 chip：「姿势 N / 人像 N / 服装 N」，单选，N 是当前筛选后的条数。
  - 姿势多一行视角筛选：全部 / 正面 / 斜前 / 侧面 / 背面 / 俯视 / 仰视（取数据里实际出现的角度）。
  - 两列网格，格子显示缩略图（`thumbs/…`，按显示尺寸解码）和名字。用 builder 懒加载，只构建看得见的格子。
  - 底部一行：当前文件夹路径 +「换文件夹」。
- 点一个格子，弹出 `InkMenuPanel` 菜单：
  - **当姿势参考 / 当服装参考 / 当长相参考 → 〈当前选中的配置节点名〉**：按格子的类别显示其中一项，三类走同一套逻辑。下面以姿势为例。可用条件三条，不满足就置灰并写原因，绝不连一条用不上的线：
    1. 恰好选中一个**图像或视频配置节点**。镜头（shot）节点不算：生成侧只认图像 / 视频配置（`generation_controller.dart:179-181`），连到 shot 上的参考生成时永远不会被读。选中的是 shot 时，原因写「选中这一镜的图像或视频配置」。（我的判断）
    2. 这个节点当前用的服务商收参考图（能力 `maxRefImages > 0`）。否则原因写「〈服务商〉不支持参考图，换一个模型再试」。注意：默认的 Gemini 图像不收参考图，目前收的只有 wanx-image（1 张）、kling-v3-omni、wanx-r2v。（我的判断，理由是 B′ 定下的「不许悄悄跳过」）
    3. 参考图配额没满（与 `ref_image_budget` 同一个口径，含挂载角色的图）。满了的话原因写「参考图已满 N / N」。这一镜已经有同类别的参考库图时是替换，不占新名额，此条不判（见下方「换一张：替换」）。
  - **只放进画布**：放在视口中心，与工具条建节点同一套落点规则。
  - **存为角色**：只对人像可用，其他类别置灰。先弹 `InkNameDialog` 起名，默认填条目标题。
- 还没设文件夹、或文件夹里找不到数据文件时：网格区域换成说明和「选择参考库文件夹」按钮（file_selector 的 `getDirectoryPath`）。
- 「本画布 / 项目全部」两段的行为一点不变。

### 数据

- 文件夹路径存进偏好设置（`config/preferences.json`，新键 `reference_library_root`，可为空）。偏好设置原本就是 JSON，不涉及数据库，不需要迁移。
- 读法：一个格式适配器，读文件夹里的 `data/pose-zh.json`、`data/portrait-zh.json`、`data/costume-zh.json`、`data/costume-shisei-zh.json`。JSON 字段名是中文（「体系」「姿势名称」「角度」「缩略图」「原图」「检索」等），作为协议字面量放进常量。
- 条目统一成一个手写不可变值对象 `ReferenceItem`：id、类别、名字、子类、角度（可空）、缩略图绝对路径、原图绝对路径、检索文本。
- 读一次放内存，按文件夹缓存。换文件夹时让它失效。大约 3,000 条，几 MB 的 JSON，读取放在后台 isolate 里做。
- 单个文件缺失或格式错误：跳过那个类别，并记一条 warn。四个文件全都读不到，就当作「不是参考库文件夹」。
- 某条的原图文件不存在：格子照样显示，点了之后出错误卡。
- 成人向内容默认隐藏：姿势里的「全身单人・性感系」「双人缠绵」，服装里的「内衣・睡衣」「性感穿搭」。这一版不提供开关，以后要的话再加到设置里。默认可见：姿势 765，人像 1,499，服装 1,125（1,068 + 历代 57）。

### 动作

**换一张：替换**（Kerro 定）：每个配置节点上，每个类别最多只有一张参考库图。已经挂了一张姿势图，再点另一张「当姿势参考」，就断开旧的那条线，连上新的；旧的导入节点留在画布上不删。姿势和服装可以同时各挂一张。

- 认法：导入节点的 `type_config` 多存两个键，常量放在 `core/constants/import_keys.dart`：`reference_item_id`（参考库条目 id）和 `reference_category`（pose / portrait / costume）。普通导入不写这两个键。
- 替换在一个事务里完成：用 `canvasEdgesController.applySplice(SplicePlan(removeEdgeIds: 旧边, addEdges: [新边]))`。旧边 = 目标节点的 data/reference 入边中，源节点的 `reference_category` 与本次类别相同的那些。
- 选的正好是已经连着的同一张（`reference_item_id` 相同）：什么也不做，出一个「已经是这张」的胶囊。
- 项目包导入：这两个键只是 type_config 里的普通字符串，不含节点 id，重映射原样带过，不需要改 import_remapper。

- **只放进画布**：调现有的 `mediaImportControllerProvider(canvasId).importFiles`，把原图复制进项目的 `imports/`，建一个导入的图像产物节点。这是现成的「导入本地图片」路径，导出项目包时也会带上这张图。
- **当姿势参考**：先按「只放进画布」导入。导入的节点放在目标配置节点左侧，与成片落点同一套规则、方向相反。然后按上面的替换规则，在一个事务里删旧边、连新边（新节点 → 选中的配置节点，edgeType data，role reference）。连线失败的话，节点保留，出错误卡（不回滚导入；用户可以手动连）。导入节点是产物节点，按 ADR-0016 属于「钉住」语义；生成侧读的是它自己的 `image_url`，今天就能用上。
- **存为角色**：调 `charactersControllerProvider.createFromImage(name, sourceAbsolutePath: 原图)`，与角色库「新建角色」同一条路。
- 三个动作都不进撤销栈。原因：导入与建角色目前本来就不进栈，W3 的撤销范围不包括它们；连线进栈归 TOPO-7。

### 模块落点

- `lib/core/interfaces/reference_library.dart`：`ReferenceLibraryReader` 抽象（输入文件夹，输出条目列表或「不是参考库」）。
- `lib/core/models/reference_item.dart`：值对象和类别枚举。
- `lib/services/reference_library/ai_pose_gallery_zh_reader.dart`：适配器实现，带字段名常量和成人向过滤。
- `lib/core/di/reference_library.dart`：reader provider，以及按偏好设置里的路径读出的条目 provider。
- `lib/features/canvas/widgets/left_rail/`：`assets_model.dart` 的 `AssetScope` 加 `reference`；新文件 `reference_library_section.dart` 放网格 / 筛选 / 空态，`reference_library_model.dart` 放筛选和计数的纯函数，`reference_item_actions.dart` 放三个动作。`assets_panel.dart` 只负责按分段切换显示哪一块。
- ARB 新文案（中英各一份），并重新生成 l10n。
- 文件归属：`assets_panel.dart` 和 ARB 与在途 PR #324 有交集（#324 也改 ARB）。由主会话来 rebase。

### 测试（要点）

- 适配器：用 fixture 文件夹（几条假数据）测四个文件都在、缺一个、格式坏、成人向过滤、路径拼接。
- 模型纯函数：搜索、类别和视角筛选、计数。
- 动作：当姿势参考建出导入节点（带两个标记键）和一条 `data/reference` 边，目标是选中的配置节点；再选另一张姿势图时，旧边被删、新边建好、旧节点还在；同一张再点一次什么也不改；服装参考与姿势参考互不替换；没有选中、选中 shot、模型不收参考图、配额已满时置灰；存为角色只对人像可用。
- 面板：没设文件夹时显示空态；切分段后两类内容不串。
- 每条新用例都做变异实测（拿掉实现要变红）。

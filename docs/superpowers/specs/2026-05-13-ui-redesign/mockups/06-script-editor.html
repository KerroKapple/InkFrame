INT. 灯塔脚下 — 夜
海风扑打着窗，灯塔的光在浓雾里像一颗缓慢转动的心脏。
少年
（低声）
"它真的还在转吗？"
他抬起手腕，怀表的秒针几乎察觉不到地颤动了一下。然后又一次。
玻璃罩下的金色刻度像被人涂了一层很薄的蜂蜜。
老灯塔守
"它从来没停过。停的是听它的人。"
少年没有回应。他把怀表轻轻放回口袋，转身看向窗外。
第一缕光，从海面尽头浮起来。
INT. 木屋 — 凌晨
屋内只剩炉火的余烬。窗台上一杯茶，茶面凝着一层极淡的奶白。
老灯塔守
"明天的潮，比今天慢半拍。"

04 — 方案

三种导航结构，改动量递减

同一批断点的三种解法。1a 重建外壳，1b 把项目做成工作区，1c 不动路由只强化浮层。线框是结构示意，不是视觉稿。

1a 持久导航栏 + 可并存抽屉 建议
GALLERY
QUEUE
最左一条常驻竖向导航栏取代整屏互斥切换：Studio、当前画布、画廊、设置各占一格，切换不再销毁彼此的状态。画廊降级为画布右侧可并存的抽屉，创作时随手拉开对照，不必离开画布。设置改为浮层，从任何界面进出都回到原处。
解决
B1 B2 B6 B7 部分
代价_UnlockedShell 的互斥路由要改成并存外壳，四个 provider 的语义都得重订。改动最大的一版。 适合把画布当长时工作面的专业用户。
1b 项目工作区 + 顶部标签 建议
画布
分镜
画廊
导出
INSPECTOR
Studio 退回纯粹的项目选择层，进入项目后是一个带标签的工作区：画布、分镜、画廊、导出四个平级视图共享同一个项目上下文。分镜从两个模态升成一个真正的视图，能总览整条 narrative 链；导出也在这里获得历史列表。标签切换只换主区，检查器与队列照常。
解决
B2 B3 B4 B6 B7 B1 部分
代价要新建分镜与导出两个视图，画廊需从项目维度改为可在工作区内嵌。画廊与画布仍不同屏。 适合按项目推进、流程感强的团队用户。
1c 命令优先 + 可停靠浮层 建议
GALLERY · 浮层
⌘K
节点
产物
画布
动作
路由一行不改。命令面板从六条硬编码动作升级为跨项目、画布、节点、产物的全局搜索，成为主导航；画廊与序列预览改为可停靠的非模态浮层，允许与画布同时在场。这是三个方案里唯一不触碰 shell 结构的一版，可以先上、再决定要不要走 1a 或 1b。
解决
B2 B5 B1 部分 B7 部分
代价需要一个跨实体的搜索索引。B3 与 B6 仍然留着，层级问题没有解决。 适合想尽快缓解摩擦、暂不重构外壳。

### 2.2 工程文件

### 2.5 交付前检查
每条：14px 宽标记位（mono 11）+ 正文，行高 1.45。`✓` success、`!` accent、`✕` danger。右上角计数「N 项待处理」，0 项时显示「可交付」success 色。
检查项（顺序固定，满足的显示 ✓ 一行，不满足显示 ! / ✕）：
1. **帧率一致** — 链上全部视频产物 fps 相同。不同 → `✕` 阻断。
2. **画幅一致** — 宽高比相同。不同 → `!` 警告（EDL 可写，剪辑软件里会出黑边）。
3. **缺失产物** — 链上无视频 result 的镜。有 → `!`「00N {镜头名} 无视频产物，将导出为 {时长} 空隙并加标记」，每个缺失镜一行，超过 3 个折叠为「另有 N 个」。
4. **项目上下文** — `ShellState.project == null` → `✕` 阻断（BOARD 210 同一判据）。
5. **输出目录可写** — 不可写 → `✕` 阻断。

存在任一 `✕` 时主按钮禁用，Tooltip 写第一条阻断原因。

### 2.6 底部摘要（固定，不随滚动）
surface2 底，上 1px borderStrong，12 内边距，两行 11px fg5：
- 「输出」 右侧 mono `<项目目录>/exports/`（过长中间省略）
- 「包含」 右侧「{N} mp4 · 1 edl · metadata.json」，N 为实际有产物的镜数

## 3. 执行流程

主按钮在标签栏右侧（已有）。点击：
1. 二次校验检查项，有阻断即止。
2. 建目录 `<项目目录>/exports/`（已存在则覆盖同名文件，不清目录）。
3. 拷贝媒体（逐文件，保持源），写 EDL，写 metadata.json。
4. 进度：标签栏「序列」标签右侧 12px 进度环 + 主按钮文案变「交付中 3/8」。
5. 结束：面板顶部 32px 结果条（成功 surface5 底 + success ✓「已交付到 {目录}」+「打开文件夹」「复制路径」；失败 accentWash 底 + danger ✕ + errorCode 原串 +「重试」）。结果条手动关闭或下次交付时替换。

**锁标签**：交付进行中，标签条整体 `IgnorePointer` + 降 0.5 不透明度（除序列标签本身），⌘K 不开，设置浮层不开。Esc 不中断。窗口关闭按钮仍可用（不劫持关窗），关窗时中断交付并清理半写的 EDL（媒体文件保留）。
